# Simple Interest Calculator

# Description
A Simple Interest Calculator calculates the interest earned or paid on a principal amount over a specified period at a fixed annual interest rate.

# Formula
Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal: The initial amount of money.
- Rate: The annual interest rate in percentage.
- Time: The time period in years.

# Example
- Principal: 10,000
- Rate: 5%
- Time: 2 years

Calculation:

Simple Interest = (10,000 × 5 × 2) / 100 = 1,000

Simple Interest: 1,000

Total Amount: 11,000

# Features
- Calculates simple interest.
- Uses principal, annual interest rate, and time.
- Displays the interest and total amount.
